# SteamSync (Dota 2 Settings Synchronizer) — Unofficial Multi-SSD Fix

> **Внимание / Disclaimer**:
> Данное приложение **не является моей авторской разработкой**. Это неофициальный комьюнити-апдейт утилиты **SteamSync** (by Freaks).
> **Автор оригинала**: Discord: fastdebug
> Разработчик оригинального проекта забросил проект и не обновляет его, из-за чего пользователи столкнулись с критической проблемой: программа видела аккаунты только если папка Steam находилась по пути по умолчанию (C:\Program Files (x86)\Steam). Если Steam был установлен на другой SSD или нестандартный раздел, аккаунты не определялись.

---

## Что исправлено в версии 1.0.2:
- **Автопоиск Steam на любых SSD и разделах**:
  - Автоматическое чтение путей из системного реестра Windows (HKCU\Software\Valve\Steam, HKLM\SOFTWARE\Valve\Steam).
  - Определение расположения Steam через запущенный процесс Steam.exe.
  - Сканирование корневых каталогов всех подключенных дисков (C: — Z:).
- **Умная оценка библиотек**:
  - Если найдено несколько мест со Steam, алгоритм проверяет наличие данных Dota 2 (папка 570) и активность профилей.
- **Резервный выбор папки**:
  - Если Steam находится в нестандартном месте, открывается нативное окно выбора папки, а путь сохраняется в конфиг.
- **Поддержка лоадера Umbrella**:
  - Добавлена поддержка путей C:\umb\UmbrellaLoader.exe и других директорий.
- **Единый автономный загрузчик**:
  - Программа упакована в SteamSync_Setup.exe — не требует установленных архиваторов и запускается на любой Windows 10/11.
